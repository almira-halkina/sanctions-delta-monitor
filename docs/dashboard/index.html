Restricted-Party Change Monitor

What changed on the OFAC, BIS and EU lists, and who else became restricted because of it? The lists can only answer the first half of that question. This page shows how the pipeline answers the second.

00 · Read this first

What's real on this page and what's synthetic

The pipeline, its parsers and the legal rules are real, and they have been run against the live lists. The worked example that most of this page walks through is a synthetic scenario. Every section carries a label saying which kind of data it shows.

Real
  • The code: parsers for the OFAC, EU, BIS and Federal Register formats, the differ, the classifier, the ownership closure and the reconciliation checks.
  • The three legal regimes, their thresholds and citations, and the BIS Affiliates Rule's suspension and scheduled reimposition on 10 November 2026.
  • The real lists: entry counts, entity types, programmes, countries and registry-ID coverage, parsed from the regulators' own files on 19 August 2026.
  • The Federal Register documents the rulemaking watch matched on that live run.
  • The failed live run of 18 August 2026 in Reconciliation.
Synthetic
  • Every company and person in the demo, including Volna, Nemiga, Baltic Marine, Meridian and Aral. None of them exist. Nothing on this page is an allegation about any real party.
  • The two list publications of 3 and 4 August 2026 and the eight changes between them. They are written in the regulators' exact file formats, but the contents are invented.
  • The ownership graph: every stake, control right, registry name and filing date on it.
  • Everything computed from those: the restricted, released and promoted companies, the regime comparison, and the demo's reconciliation checks.
  • The two Federal Register documents in the demo, including a request for comment on the Affiliates Rule. BIS has not published them.

Why the walkthrough uses synthetic data

  1. A real before-and-after didn't exist yet. Regulators overwrite their lists in place and keep no history, so a diff needs two snapshots this pipeline archived itself. The first live run, on 19 August 2026, was the baseline. Change detection on real data starts from the next live run.
  2. The real ownership graph hasn't been assembled. The ownership closure needs shareholding data. The free sources (UK Companies House PSC filings and GLEIF) are supported by the code but haven't yet been built into a graph for this project. Without one, a live run would report zero derived restrictions, which is a false negative, not a finding.
  3. Naming real companies would be an accusation. On real data, a derived restriction says a named company is controlled by a sanctioned party. Publishing that needs an evidence standard a portfolio demo can't meet. Invented companies show the method without asserting anything about anyone.
  4. The scenario is built to test every hard case. It contains each edge case exactly once: a two-hop chain, a stake of exactly 50%, stakes that only add up across lists, a control right below 50%, an undisclosed stake, a delisting that releases subsidiaries, and a promotion that only looks like a release. A real day's publications may contain none of them. The test suite pins the results, so a change to the legal reading fails the build.
  5. It still exercises the real parsers. The fixtures are generated by code in the regulators' wire formats, and CI regenerates them and fails if they were edited by hand. The same parsers then read the live files: on 19 August they parsed exactly the number of entries OFAC and the EU declare in their own files.

02 · Diff and classifySynthetic demo data

Most changes don't move the entry count

The differ compares every field of every entry, not the number of rows. On this run OFAC added one party and delisted another, so its count stayed flat while six entries changed. Several of those changes alter which names a screening engine will match.

04 · The legal readingReal rule · synthetic example

Ownership is not multiplied along the chain

This is the case that separates a correct implementation from a plausible one. Once a subsidiary is restricted by the rule, it counts as a restricted owner in its own right, and its full stake passes down.

So propagation is a fixed point

restricted = {seeds}
repeat until no change:
    for each entity not yet restricted:
        if sum(stake held by each restricted owner) ≥ threshold:
            mark restricted

The restricted set only grows and can't exceed the number of companies, so the loop always stops, even on circular shareholdings like the 5% stake running back up the Volna chain.

Unknown is not zero

Registers often omit percentages. A company with a restricted owner whose stake is unrecorded can't be cleared and can't be restricted from the filing alone, so it goes to a research queue as Indeterminate.

UK PSC filings report bands, not numbers. A band is read at its floor: "25% to 50%" counts as 25%, so a filing never creates a restriction it can't evidence.

05 · Three regimesReal rules · synthetic companies

One graph, three different answers

The regimes are parameters, not separate code paths. The same graph runs through each one, and the differences come from four settings: the threshold, whether it's "50% or more" or "more than 50%", which lists seed the closure, and whether control without ownership counts.

Rows marked on the left are restricted or undecided under at least one regime and clear under another. Notes summarise docs/findings.md.

07 · ReconciliationReal failed run · synthetic demo checks

The pipeline checks itself before it reports

Monitoring pipelines fail quietly. A parser that drops half a list produces thousands of false delistings, and a stale download looks like a quiet day. Neither raises an error, so the checks run first and their result sits above the findings in the brief.

09 · Rulemaking watchReal date and documents · synthetic demo documents

Some changes never touch a list

The BIS Affiliates Rule added no entries to any list, yet it widens the restricted set by an unpublished amount. Its suspension was part of a US–China arrangement, so the date can move. The monitor watches the docket instead of trusting the calendar.
